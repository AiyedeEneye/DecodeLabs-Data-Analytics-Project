# E-commerce Sales Data Analysis

## Project Overview

This project analyzes e-commerce sales data to uncover key trends and insights into business performance. The analysis focuses on product performance, payment methods, order status, referral sources, and coupon code usage.

The project was completed as part of my Decode Labs data analysis project, using Excel and Power Query for data cleaning, transformation, analysis, and visualization.

## Objectives

- Analyze overall sales and order performance
- Identify top-performing products
- Understand customer payment preferences
- Examine order status and identify potential operational issues
- Evaluate referral sources and customer acquisition patterns
- Analyze coupon code usage and revenue performance
- Present key findings through an interactive dashboard

## Tools Used

- Microsoft Excel
- Power Query
- Pivot Tables
- Excel Charts & Visualizations

## Key Findings

- 1,200 orders were analyzed.
- 6,552 items were sold.
- Total revenue was approximately ₦1.26 million.
- Chair recorded the highest quantity sold and highest revenue.
- Online payment had the highest number of orders.
- Instagram was the leading referral source by order volume.
- FREESHIP was the most-used coupon and generated the highest revenue.
- Cancelled orders represented the largest order-status category, highlighting an area that requires further investigation.

## Project Outcome

The analysis provides insights that can help the business understand its sales performance, customer behaviour, marketing channels, and promotional strategies while identifying areas for operational improvement.
